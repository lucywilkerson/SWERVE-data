From Zenodo:
"Magnetic Data (Magnetic_Data.zip): Includes geomagnetic data from April 24, 2023, from three CARISMA magnetometer stations in Alberta, Canada: Fort Chipewyan (FCHP), Fort MacMurray (MCMU), and Ministik Lake (MSTK). Also included is the geomagnetic data from November 4th, 2021, at MSTK used in the supporting information of the paper. Raw data are from CARISMA (www.carisma.ca)
...
GIC Data (20230424_hallprobe_data.mat): The GIC data file includes the UT time (GMT+6 = Mountain Daylight Time) and the transformer neutral-to-ground current data measured at two substations in central Alberta on 2023-04-24. See Parry et al., 2025 (Space Weather), for more details."

Link to Zenodo repository for this project: https://zenodo.org/records/16748607

Zipped magnetometer data is in 'orig' folder. Unzipped files are in 'mag' folder. GIC data is in 'gic' folder.
